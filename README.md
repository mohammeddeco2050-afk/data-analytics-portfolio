# Customer Churn Exploration

> **Independent practice project. All data is synthetic and generated for demonstration. This is not employer/client data and sample findings are not real business outcomes.**

## Business question
Compare churn rates across contract type, tenure and recent support contact using generated customer records. Patterns are exploratory, not causal.

## Tools
Python, pandas and SQL (query file included). Charts in `outputs/` are generated from the synthetic dataset.

## Files
- `customer_churn_sample.csv` — synthetic dataset
- `analysis.py` — beginner-readable analysis script
- `queries.sql` — SQL practice queries
- `outputs/` — charts created from the dataset

## Run it
1. Install Python 3.10+.
2. Run `python -m pip install pandas`.
3. Run `python analysis.py` in this folder.
4. Read the script line by line and explain the calculations in your own words.
5. Import the CSV into SQLite using the table name shown in `queries.sql` to practise SQL.
